Extract all advertisements and return their bounding boxes.
The original size of the page is {width} x {height} pixels.

Return only a JSON object in exactly this format, with no additional commentary:

{{
    "advertisements": [
        {{"box": [x0, y0, x1, y1]}},
        {{"box": [x0, y0, x1, y1]}}
    ]
}}

Coordinates are pixels in the original page, with (x0, y0) the top-left corner and
(x1, y1) the bottom-right. The key must be "box". Return an empty list if the page
contains no advertisements.
